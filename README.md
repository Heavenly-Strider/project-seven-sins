# Project Seven Sins

Статический сайт с главной страницей, последовательным чтением, содержанием, архивом персонажей и страницей автора.

## Версия сайта

Текущая версия задаётся в `site-config.js`. Меняйте значение `version` только в этом файле. Скрипт подставляет версию в элементы с атрибутом `data-site-brand`.

Версия 0.9: усилена инициализация страницы содержания, добавлена понятная ошибка при недоступном списке материалов; порядок материалов внутри групп определяется полем `order`.

## Материалы и главы

Текст глав хранится в отдельных `.txt`-файлах в `reading/chapters/`. Порядок чтения и настройки материалов задаются в `reading/materials.js`. Синтаксис текста, декоративные блоки и правила добавления глав описаны в `reading/README.md`.

## Язык интерфейса

Язык интерфейса выбирается в меню в верхней правой части главной страницы и внутренних страниц. Выбор сохраняется в браузере. Переводы интерфейсных элементов находятся в `language.js`. Если строка не переведена, остаётся русский вариант.

Авторский текст, включая главы, досье и описания вселенных, автоматически не переводится. Перевод такого содержимого создаётся вручную и должен сохранять авторский смысл и канон.

## Запуск

Откройте проект через локальный веб-сервер или разместите его на веб-хостинге. Загрузка отдельных файлов глав может не работать при открытии страниц напрямую через `file://`.
