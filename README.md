# Project Seven Sins

Статический сайт с содержанием, последовательным чтением, архивом персонажей и страницей автора.

## Редактирование материалов

Инструкция по добавлению глав и синтаксису текста находится в `reading/README.md`. Текст глав хранится в `reading/chapters/`, а порядок и настройки материалов задаются в `reading/materials.js`.

## Запуск

Откройте проект через локальный веб-сервер или разместите его на веб-хостинге. Загрузка отдельных файлов глав может не работать при открытии страниц напрямую через `file://`.
