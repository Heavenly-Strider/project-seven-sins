# Добавление материалов в читалку

## Где хранится текст

Текст каждой главы хранится отдельным файлом в `reading/chapters/`. Используйте расширение `.txt`. В `reading/materials.js` находится только список материалов и их настройки.

## Как добавить главу

1. Создайте файл в `reading/chapters/`, например `chapter-003.txt`.
2. Напишите текст в синтаксисе ниже.
3. Добавьте запись в конец массива `window.PSS_MATERIALS` в `reading/materials.js`.
4. Укажите путь относительно папки `reading/`, например `chapters/chapter-003.txt`.
5. Проверьте главу на сайте. Порядок записей в массиве задаёт порядок чтения.

Пример записи:

```js
{
  id: "chapter-003",
  type: "chapter",
  title: "Название главы",
  sin: "Гнев",
  subtitle: "Краткое описание",
  path: "chapters/chapter-003.txt"
}
```

`id` должен быть уникальным и после публикации не меняться: он используется для ссылок и прогресса чтения. `type` принимает значение `chapter` или `document`. В `sin` указывайте название темы точно так, как оно записано в `sin-themes.js`. Поле `subtitle` можно оставить пустым.

## Синтаксис текста

Пишите обычный текст. Не добавляйте HTML-теги.

```text
= Заголовок главы =

Первый абзац. Пустая строка начинает новый абзац.

Второй абзац. Текст можно переносить на следующую строку внутри абзаца.

== Заголовок раздела ==

=== Подраздел ===

**Жирный текст**
//Курсивный текст//

* Пункт маркированного списка
* Ещё один пункт

# Пункт нумерованного списка
# Следующий пункт

> Цитата

----

[[https://example.com|Текст внешней ссылки]]
```

Правила:

- `= Заголовок =` создаёт заголовок раздела главы.
- `== Заголовок ==` создаёт заголовок подраздела.
- `=== Заголовок ===` создаёт заголовок меньшего уровня.
- Пустая строка разделяет абзацы.
- `**текст**` выделяет жирным, `//текст//` курсивом.
- Строки с `* ` создают маркированный список, строки с `# ` создают нумерованный список.
- `> ` в начале строки оформляет цитату.
- `----` на отдельной строке добавляет разделитель.
- `[[URL|текст ссылки]]` создаёт ссылку. Разрешены адреса `https://`, `http://` и `mailto:`.

## Важные ограничения

- Не вставляйте HTML, JavaScript или iframe. Используйте только описанный синтаксис.
- Не меняйте `id` уже опубликованного материала без необходимости.
- Не добавляйте неподтверждённые сюжетные сведения.
- Для проверки локально запускайте сайт через веб-сервер. Браузеры обычно блокируют загрузку файлов глав при открытии `index.html` через `file://`.
- Прогресс чтения хранится в текущем браузере и не синхронизируется между устройствами.
