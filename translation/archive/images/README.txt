Изображения архива персонажей

Положите портрет в эту папку и у нужного персонажа в `script.js` укажите `image: "images/risto.webp"` (путь относительно папки `archive/`) либо путь от корня сайта, например `image: "/ProjectSevenSins/archive/images/risto.webp"`. Для вложенных копий сайта абсолютный путь должен соответствовать фактическому URL их папки. Поле необязательно: пустое значение показывает `NO IMAGE`. Допустимые форматы: AVIF, GIF, JPG/JPEG, PNG, WebP. Кадрирование: 3:4, `object-fit: cover`.
