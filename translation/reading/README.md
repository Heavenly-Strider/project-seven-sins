# Добавление материалов в читалку

## Где хранится текст

Текст каждой главы хранится отдельным файлом в `reading/chapters/`. Используйте расширение `.txt`. Список материалов и порядок чтения задаются в `reading/materials.js`.

## Как добавить главу

1. Создайте текстовый файл в `reading/chapters/`, например `chapter-003.txt`.
2. Напишите текст с помощью синтаксиса из этой инструкции.
3. Добавьте запись в массив `window.PSS_MATERIALS` в `reading/materials.js`.
4. Укажите путь относительно папки `reading/`, например `chapters/chapter-003.txt`.
5. Проверьте главу через локальный веб-сервер или опубликованный сайт.

Пример записи в `materials.js`:

```js
{
  id: "chapter-003",
  type: "chapter",
  title: "Название главы",
  sin: "Лень",
  subtitle: "Краткое описание",
  path: "chapters/chapter-003.txt"
}
```

`id` должен быть уникальным. После публикации не меняйте его без необходимости: он используется в ссылках и прогрессе чтения. `type` принимает `chapter` или `document`. Значение `sin` должно совпадать с названием темы в `sin-themes.js`. Порядок записей в массиве задаёт последовательность чтения. Поле `subtitle` можно оставить пустым.

## Обычный текст и форматирование

Пишите обычный текст. HTML-теги добавлять не нужно.

```text
= Заголовок главы =

Первый абзац. Пустая строка начинает новый абзац.
Продолжение этой строки будет частью того же абзаца.

== Заголовок раздела ==

=== Заголовок меньшего уровня ===

**Жирный текст**
//Курсивный текст//
`Моноширинный фрагмент кода или синтаксиса`

* Пункт маркированного списка
* Ещё один пункт

# Первый пункт нумерованного списка
# Второй пункт

> Текст цитаты.
> Продолжение цитаты.

----

[[https://example.com|Текст внешней ссылки]]
```

Поддерживаются следующие конструкции:

- `= Заголовок =`, `== Заголовок ==` и `=== Заголовок ===` создают заголовки разных уровней.
- Пустая строка разделяет абзацы.
- `**текст**` выделяет жирный текст, `//текст//` выделяет курсив, а `` `текст` `` оформляет моноширинный фрагмент.
- `* ` создаёт маркированный список, `# ` создаёт нумерованный список.
- `> ` в начале строки оформляет цитату.
- `----` на отдельной строке добавляет разделитель.
- `[[URL|название]]` создаёт внешнюю ссылку. Разрешены адреса `https://`, `http://` и `mailto:`.
- `` `текст` `` выделяет встроенный фрагмент кода.

## Декоративные блоки

Блок начинается строкой `::: тип` и заканчивается отдельной строкой `:::`. Между ними можно использовать обычную разметку: абзацы, заголовки, жирный и курсивный текст, списки, цитаты, разделители и ссылки. Блоки можно размещать между обычными абзацами.

### Тёмный блок

```text
::: dark
= Служебная запись =

Текст на тёмном фоне.
**Важная деталь.**
:::
```

### Светлый блок

```text
::: light
= Письмо =

Этот текст будет на светлом фоне с тёмным шрифтом.
:::
```

### Блок с рамкой

```text
::: frame
Текст внутри тонкой цветной рамки.
Можно добавить несколько абзацев.
:::
```

### Документ или файл

```text
::: file
= АРХИВНАЯ КОПИЯ =

Номер документа: 014.
Статус: **Не подтверждён.**
:::
```

Этот блок оформляется как отдельный бумажный документ. Надпись в верхней части является декоративной и не заменяет текст внутри.

### Досье с фотографией и полями

```text
::: dossier
photo = chapters/images/portrait.jpg
name = Имя персонажа
alias = Прозвище
field = Статус | Активен
field = Уровень доступа | III
field = Местонахождение | Не установлено
---

Здесь можно написать дополнительное описание досье.
Поддерживается обычная разметка текста.
:::
```

Поля до строки `---` задают оформление досье:

- `photo = путь` указывает изображение. Путь задаётся относительно папки `reading/`. В примере файл должен находиться в `reading/chapters/images/portrait.jpg`.
- `name = текст` задаёт имя в заголовке досье.
- `alias = текст` задаёт подпись под именем.
- `field = Название | Значение` добавляет поле. Можно добавить несколько строк `field`.
- `---` завершает список полей и начинает основной текст досье.

Фотография необязательна. Если поле `photo` не указано, файл отсутствует или путь некорректен, появится пустая область с надписью `NO IMAGE`. Используйте локальные изображения JPG, PNG, WebP, GIF или AVIF. Внешние URL и пути с переходом в родительские папки не поддерживаются. Фотография обрезается под фиксированную область, поэтому лучше выбирать портретное изображение.

Пример без фотографии:

```text
::: dossier
name = Имя персонажа
alias = Прозвище
field = Грех | Лень
field = Вселенная | Название мира
---

Дополнительная информация.
:::
```

## Ограничения и проверка

- Не вставляйте HTML, JavaScript, iframe или другие исполняемые элементы.
- Закрывайте каждый декоративный блок отдельной строкой `:::`. Не используйте этот синтаксис в обычном тексте как отдельную строку.
- Не вкладывайте декоративные блоки друг в друга. Сначала закройте текущий блок, затем начинайте следующий.
- Не меняйте `id` опубликованного материала без необходимости.
- Не добавляйте неподтверждённые сведения о персонажах и мирах.
- Для загрузки глав запускайте сайт через веб-сервер. При открытии страницы через `file://` браузер может блокировать загрузку файлов.
- Прогресс чтения хранится в текущем браузере и не синхронизируется между устройствами.
