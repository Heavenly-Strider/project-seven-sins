= Глава III. Инструкция по ничегонеделанию =

Это **демонстрационная глава**, а не каноническое описание Ристо Каареля или его вселенной. Её задача скромнее: показать, какие кнопки нажимает автор, чтобы читатель видел красиво оформленный текст, а не техническую кухню.

== Как читать эту главу ==

Обычный текст превращается в абзацы. Пустая строка отделяет один абзац от другого, а заголовки с одним, двумя или тремя знаками равенства создают разные уровни разделов.

**Две звёздочки** выделяют жирный текст, а //две косые черты с каждой стороны// превращают фразу в курсив. Никакой магии, просто пунктуация, которая наконец-то нашла работу.

* Звёздочка в начале строки создаёт пункт списка.
* Следующая звёздочка создаёт следующий пункт.
# Решётка в начале строки создаёт нумерованный список.
# Ещё одна решётка продолжает список, а не вызывает службу поддержки.

> Цитата начинается с символа `>` и пробела.
> Если цитата занимает несколько строк подряд, они останутся одной цитатой.

----

Разделитель выше рисуется четырьмя дефисами. Он не закрывает главу, не вызывает дождь и не выдаёт автору дополнительный выходной.

::: dark
== Тёмный блок: важное предупреждение ==

Этот блок предназначен для заметок, которые должны выглядеть серьёзно. Например: **не забывайте закрывать каждый декоративный блок отдельной строкой `:::`**.

Если забыть закрывающую строку, парсер может продолжить считать следующие строки частью блока. Даже у синтаксиса есть предел терпения.
:::

::: light
== Светлый блок: письмо из отдела оформления ==

Здравствуйте! Мы получили вашу заявку «Сделать красиво, но без переписывания всей страницы». Заявка одобрена. Для изменения цвета текста используйте привычные выделения, а не вставляйте HTML: этот редактор принимает собственный синтаксис и не обязан угадывать ваши намерения.
:::

::: frame
== Блок с рамкой ==

Рамка просто выделяет фрагмент. Внутри неё работают те же заголовки, абзацы, жирный текст, курсив, списки, цитаты и ссылки.

Ссылка записывается так: [[https://example.com|пример внешней ссылки]]. Она открывается отдельно, потому что даже демонстрационная глава не должна бесцеремонно выталкивать читателя из документа.
:::

::: file
= СЛУЖЕБНАЯ КАРТОЧКА =

**Документ:** PSS-DEMO-003  
**Назначение:** показать оформление бумажного файла  
**Статус:** учебный пример, не канон  
**Срок выполнения:** после чашки чая, но до следующей чашки чая.
:::

::: dossier
name = Демонстрационный персонаж
alias = Сотрудник отдела отложенных дел
field = Грех | Лень (тема примера)
field = Статус | Временно отсутствует на рабочем месте
field = Любимый инструмент | Кнопка «Продолжить позже»
field = Каноничность | Не является частью лора
---

Это досье показывает поля `name`, `alias` и `field`. Каждое поле записывается отдельной строкой до разделителя `---`. После разделителя идёт обычный текст, который поддерживает тот же синтаксис, что и вся глава.

Поле `photo` необязательно. Если оно не указано, сайт оставляет фиксированное место с пометкой `NO IMAGE`. Если портрет понадобится, строка будет выглядеть примерно так: `photo = chapters/images/demo-portrait.webp`. Файл при этом должен действительно существовать по указанному пути.
:::

== Ссылки и финальная проверка ==

Внешняя ссылка записывается в формате `[[URL|подпись]]`. Допустимы адреса `https://`, `http://` и `mailto:`. Не используйте для ссылок HTML-код, скрипты или iframe: глава является текстовым документом, а не свободной зоной для внедрения веб-приложений.

Перед публикацией проверьте три вещи:

# У каждого блока `::: dark`, `::: light`, `::: frame`, `::: file` или `::: dossier` есть закрывающая строка `:::`.
# В записи материала указан уникальный `id`, правильная тема `Лень` и путь к файлу.
# В досье нет выдуманных сведений, которые случайно объявили себя каноном.

На этом инструкция заканчивается. Автор может отдохнуть, читатель может продолжить чтение, а сотрудник отдела отложенных дел наконец-то откроет документ, который собирался открыть с утра.
